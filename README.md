## Featured project

**[FinLLM](https://github.com/Prashasti9/FinLLM)**: a local AI assistant for anti-money-laundering alert review.
A Dagster daily pipeline with data contracts feeds rules, an anomaly model and an XGBoost classifier tracked in MLflow. Flagged customers become cases that a tool-using LLM agent investigates, citing the FFIEC guidance, while an analyst makes every decision and those decisions retrain the model. Every LLM call is traced and evaluated. Runs entirely on a laptop with Ollama.
